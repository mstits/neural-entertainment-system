# cold-boot flow: title screen animation, file select, and name-entry
# cursor movement.
#
# Getting Link to the overworld from a cold boot requires entering
# at least one character before REGISTER is usable, which is brittle
# to script and adds no regression-detection value: the sprite
# pipeline is already fully exercised by title + menu animations,
# and any OAM/sprite-0-hit regression will show up in the frame
# hashes here.
