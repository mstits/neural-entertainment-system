# v21 synthesis — the hazard verdict, and the new build order

Round v21 was commissioned on the Phase-3 falsification (control 31/100,
masked 0/100, veto blocking the control's own action 77.4% of the time
where active). Report: `~/Documents/research-consult/responses/
20260822T223230Z_v21_hazard_decision_rule.md`. What it settled:

## 1. Our diagnosis is the canonical failure, with a second half we missed

Behavior-policy mismatch of pessimistic shields is a documented Safe-RL
pathology: a shield synthesized under a random behavior policy classifies
every skill-dependent maneuver as lethal, confining the agent to a "safe"
set that is an absorbing failure state (stand still, die to timer/enemy).

The half we had NOT diagnosed: **gradient corruption**. Rejection-based
shields fail to converge even with mathematically perfect safety
information, because PPO updates as if the executed trajectory came from
its own unshielded distribution. Our first (void) run hid this — the NaN
froze the actor before the corruption could even matter.

## 2. The correct label is the viability kernel, not the current policy

Relabeling with current-policy continuations is NOT the fix — it is
non-stationary and self-fulfilling (regions a weak early policy died in
stay avoided forever). The correct construct: label (s, a) safe if ANY
continuation survives — max-aggregation over a small budgeted search from
each fork, approximating the viability kernel. Our fork machinery
(~2,500 worker-steps/s) supports this directly. This is a NEW experiment
requiring its own registration; not scheduled yet.

## 3. Hard vetoes are structurally doomed under sticky actions

An action-space shield can only restrict what the agent REQUESTS; the
25% sticky repeat is forced by the environment and cannot be vetoed. Any
state whose survival requires a guaranteed next input fails at 0.25^k
regardless of shield quality. If hazard knowledge re-enters training it
must be differentiable and soft — Lagrangian CMDP cost or a finite logit
bias — never a truncation.

## 4. The 0.917 discriminator is salvageable — ranked

1. **Go-Explore cell-selection weighting**: prioritize restoring to
   high-random-hazard cells. The off-policy property is DESIRABLE here —
   it identifies exactly where unguided exploration fails. Cheapest lift.
2. Curriculum difficulty scorer over restart states.
3. Death-clustering diagnostic (offline analysis only).

## 5. New build order: options first

Sticky noise at 60Hz decision frequency compounds; shrinking decision
frequency shrinks the noise surface itself. The veto tried to bandage
symptoms; temporal abstraction removes the cause. **Options/temporal
abstraction is now the #1 capability build**, with a principled
combination available later: the hazard model as the option TERMINATION
condition (interrupt a macro-action when predicted risk spikes), where
its conservatism is again benign.
