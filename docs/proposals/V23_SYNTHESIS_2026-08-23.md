# v23 synthesis — the five-game plan, adopted with amendments

Source: user-run Deep Research answering our v23 prompt ("NES AI
Advancement Plan", 13pp). Unlike the two prior surveys, every
recommendation arrives with mechanism -> decisive experiment -> numeric
gate -> kill criterion -> falsification mapping, inside our purity line
and M4 envelope. Total plan: ~3.7 M4-days across five gated experiments.

## The unifying mechanism: SIMCE

Structural Irreversible Memory and Capability Engine — the one build
that serves all five games:
1. 3-probe stability filtering (volatile vs persistent RAM regions) —
   we own this (discover_observables).
2. Irreversible-bit tracking: RAM bits that flip 0->1 on interaction and
   never revert during normal play = candidate objective/capability
   flags, found structurally, never named.
3. Counterfactual splicing verification: splice a candidate bit into a
   blocked save-state; if reachability extends past the old boundary,
   the bit is a validated capability flag. 20 rollouts/bit, RANDOM-bit
   splices as false-positive controls.
This is v16's design made operational; build first (~0.5 day).

## Per-game, in build order

**Contra (0.5 day, cheapest win):** archive key K=(x,y,z_obj) where
z_obj = discovered irreversible bits. THE 5-MINUTE FALSIFIER before any
search run: take one trajectory that destroys a base target and one that
idles, and require the candidate key to differ between them
(Delta_key > 0); a key blind to destruction is rejected for pennies.
AMENDMENT (purity): the "destroying" trajectory must come from OUR OWN
prior search rollouts (the solver has destroyed targets incidentally),
never from a scripted/authored input sequence.
Gate: all stage-1 base targets + Stage 2 transition within 8.0e7 steps.
Kill: falsifier zero, or 80k cells without passing the wall.

**Zelda + Metroid (1 day):** room identity from PPU NAMETABLE VRAM
hashes — hardware surface like pixels/OAM, not a game RAM map, hence
purity-legal. Three filters: PPU scroll-register stability (>=6 frames)
gates hashing; 32-bit hash of the tile array (Metroid: 8x8 macro-tile
downsample, high-variance animated tiles masked); edges validated by
counterfactual rollback under sticky p=0.25 with >=80% reproducibility.
Archive key (R, x_local, y_local); frontier score
(1/sqrt(N))(1 + l_exit*U(R) + l_cap*C_flag) — new-room rate alone is
insufficient because item-gated barriers create false dead ends.
Gates: Zelda D1 mapped + Triforce 1 within 1.5e8 steps; Metroid first
shaft + Morph Ball + Missile within 1.8e8.
Kill: <3 stable rooms after 5e7 steps, or >50% false room splits.
NOTE: needs a nes_core VRAM/nametable peek API (core work, fidelity-
adjacent, small).

**Castlevania (1 day):** the composition experiment — (a) hazard-
weighted Go-Explore cell selection P(c) ~ exp(beta*h(c))/sqrt(N(c))
using the salvaged 0.917 survival model exactly as v21 ranked; (b) the
commitment-options build already in flight (k in {1,2,4}, semi-MDP GAE,
duration-scaled entropy — the report independently specifies our exact
design); (c) enemy-phase archive keys from FFT periodicity of RAM/APU
(bats/Medusa spawn timers), phase discretized into 4 bins.
Gate: block-3 hall clear rate under the honest protocol (100 eps, 2
seeds). Kill: <5% after 1.5e8 steps, or hazard weighting concentrating
>80% of restores on immediate-death states.

**Final Fantasy (0.2 day):** CONDITIONAL PARTIAL reopen — combat
sub-systems only. Monotone-counter discovery (generalized 3-probe across
battles) finds EXP/Gold-shaped counters structurally; battle-win
lexicographic orderings (learnfun) order combat states. Main narrative
stays CLOSED: hyper-sparse non-monotone event flags need ~1e10 steps,
2-3 orders past the M4. The 4-hour probe: >=N monotone counters + >=20
consecutive win trajectories, else RPGs remain closed with receipts.
