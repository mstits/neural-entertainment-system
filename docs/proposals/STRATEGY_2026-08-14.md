## Where we actually are

Assets, honestly stated:

- **Emulator**: 793/794 boot, byte-exact interpreter, cycle-locked 29,781 cyc/frame, µs
  savestates, ~3,500 env-steps/s pooled. World-class substrate — with two documented
  integrity holes (torn multi-byte reads; savestates that silently drop in-flight DMA).
- **Solver**: beat all 32 SMB levels from power-on, live on stream. Generic machinery
  (Go-Explore, coverage recipes, heuristic inversion) proven on one game, adapters on ~13.
- **Learning track**: one honest capability (1-1 tile policy, 63–67% cold-greedy). The 1-2
  wall is no longer mysterious: the offline negative is contaminated by four implementation
  artifacts, and a decisive rehabilitate-or-close experiment is fully specified.
- **Research engine**: direct API bridge to Gemini Deep Research ($1–3/round, ~10 min,
  chainable via previous_interaction_id), ~$75–85 of budget left, plus workflow
  orchestration that just ran a 59-agent audit and a 5-agent TDD fix wave in an afternoon.

The bottleneck is **not** performance (core-bound, 21 perf commits deep, ~160× realtime).
The bottlenecks are: (1) numbers we can't fully trust, (2) one unresolved learning wall,
(3) zero unattended capability. Those are the three flywheels.

## Flywheel 1 — TRUTH (multiplies everything else)

Every fabricated frontier (gx-767) or inflated metric (PR-MDP winner) wastes an entire
campaign of compute and, worse, poisons decisions. Fixes are pure code, no compute policy
conflict, and they pay off on every future run:

1. **Micro-step torn-read guard** (audit-3 #1): at the frame boundary, clone the machine,
   advance one instruction, re-read, restore, adjudicate. Structurally eliminates torn
   reads for every profile with zero per-game classification burden. Clone-based (full
   struct), not serialize-based, so it sidesteps the DMA gap.
2. **Versioned savestate envelope** (audit-3 #4, WORLDCLASS item #2): magic header
   `SAVE` + u32 version, try-parse fallback for legacy `2048`-prefixed blobs (proven
   non-aliasing), Version2 adds in-flight OAM-DMA. Never quiesce — serialize in flight.
   All ~149k banked blobs stay loadable; golden-blob fixture locks it in.
3. **Passive pair-semantics classifier + Hampel filter** (audit-3 #5/#2): machine-generated
   carry-coupled vs composite receipts for all 11 two-byte profiles; asymmetric Hampel
   replaces median3 (no 1-frame lag on real warps).
4. **ASM lockstep for MMC1/MMC3/UNROM** (backlog P1-5): the ASM CPU runs by default on
   the library's most common mappers with zero gameplay-equivalence tests, and the Mesen
   harness already records extra divergence with ASM on. Test before trusting.

## Flywheel 2 — LEARNING (the flagship)

The product story is "an AI that LEARNED to beat the game under honest eval." Path:

1. **SMODICE rehabilitate-or-close** — the single decisive experiment, one attended
   window: regenerate transitions admitting all windows (deaths done=1, timeouts
   bootstrapped, 50/50 success/failure), train the Fenchel-dual state-occupancy objective,
   extract via weighted BC. Pre-registered rule: argmax ≥0.60 AND honest clear >0.0 →
   offline REHABILITATED (v12's pivot was premature); else → offline CLOSED soundly.
   Code lands ahead of time; the experiment itself is ~2–4 attended hours.
2. **Branch A (rehabilitated)**: scale the corrected offline recipe level-by-level — the
   solver already provides verified demos for all 32 levels. Target: majority of W1–W2
   honest-cleared by a learned policy.
3. **Branch B (closed)**: online track with the audit-4 components — monotone peak
   potential Φ̃ + Grześ death rule + Pardo truncation bootstrap, kernel-matched repeat/pass
   adversary (entropy 0.01, 10:10 epochs), SPDL honest-probe gates, pre-registered kill
   table. Only then re-consult a premise-corrected v12-r (the original v12 was built on
   the contaminated premise and its response was never captured anyway).
4. **Then the generalist** (Phase-B PLR, hold out 1-3) once single-level honest clears
   exist beyond 1-1.

Consultation cadence: experiment first, then chain the follow-up round on the completed
interaction with real numbers. Never consult on a premise an afternoon of compute could
falsify.

## Flywheel 3 — SCALE (the product surface)

The League (stratified-random unattended rotation over 793 titles) is fully designed now
(audit-2): MI agency tripwire (<0.2 ms), counterfactual nametable-diff probe, projected-
hash loop detection, pulse-width menu fuzzer, escalation ladder with hysteresis, playing-
fraction / MTTR / wrongful-reset metrics. Zero code exists. Build order:

1. Probe + loop detector + tripwire (pure additions, testable against 350 banked
   trajectories and power-on negatives — auto-labeled, nearly free).
2. Menu fuzzer + escalation controller, falsified on a 20-title supervised rotation.
3. **Decision gate (user)**: unattended compute. 793 titles × 1 h cannot be attended.
   Options: (a) sanctioned recurring unattended blocks (e.g., watchdog-gated League
   pilots with hard abort on any wrongful reset), (b) attended-only pilots during streams
   (League-as-show), (c) defer. The no-overnight rule stands until explicitly lifted.

## Operating rhythm — the loop that makes hours compound

Every attended window is bracketed by machine work:
- **Before**: code, tests, dataset generators, and pre-registered gates are already built
  and reviewed (workflows run while nobody is at the keyboard — code only, no compute).
- **During**: the user runs the experiment (minutes-to-hours, gates decide pass/fail).
- **After**: results get dossier'd, chained into a $1–3 Deep Research follow-up on the
  same interaction thread, and the response is turned into the next window's code.
